# 🐍 Python Projects  

This repository contains a collection of beginner to intermediate level Python projects I built while learning the language.  
Each project focuses on practicing fundamental programming concepts such as loops, conditionals, functions, OOP, and file handling.  

---

## 📌 Project List  

- 🎮 **Adventure Story Game** → A text-based interactive story.  
- 🎲 **Dice Dash Game** → Simulates dice rolling with random outcomes.  
- 🔢 **Guess the Number** → Classic number guessing game.  
- 🔼 **High-Low Game** → Guess if the next number is higher or lower.  
- ✍️ **Madlib TaleMaker** → Fill-in-the-blanks storytelling game.  
- ➗ **Maths Problem Quest** → Solve math challenges to win.  
- ❓ **Quiz Game** → Multiple-choice question game.  
- ✊ ✋ ✌️ **Rock Paper Scissors** → Play against the computer.  
- 🎰 **Slot Machine** → A fun slot machine simulator.  
- ⏰ **Time Conversion** → Convert 12-hour to 24-hour format.  
- 🐢 **Turtle Speedway Game** → Race using Python’s Turtle graphics.  
- ⌨️ **Typing Master** → Test your typing speed and accuracy.
